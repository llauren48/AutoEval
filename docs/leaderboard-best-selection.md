# 榜单最优成绩展示

按2026-11-12用户要求，已评审榜单默认对同一模型ID、配置版本及可比条件保留最优记录。准确率等越高越好取最高；耗时等越低越好取最低；同分保留最近记录。模型名称相同但稳定模型ID不同不会合并。

`GET /api/autoeval/v1/data-workbench/published?selection=best`为默认模式，`selection=all`返回全部已批准且证据有效的历史记录。页面“成绩展示”可切换，两种模式同时作用于排行榜和图表，不改写或删除任何成绩。

报告使用冻结的model_version_id识别模型，config_version_id与样本清单、执行参数、工具版本共同构成可比条件；正式基线、评审状态与门禁不改变。官方数据保留来源版本、披露条件及未知条件隔离。行内展示输出长度、并发和工具版本以说明不同配置的重复模型名称。

后端测试10项通过、1项基础设施用例未启用；真实API只读核对188组，默认188条、全部189条，逐组验证最优值及模型身份唯一性。浏览器验证默认best、全部切换及真实接口成功；TypeScript与构建通过。未运行模型测评，也未改动既有榜单记录。

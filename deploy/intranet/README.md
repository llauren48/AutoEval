# 内网试用部署

本目录为部署骨架，尚未完成发布与迁移验收，不能直接宣称可用。

Compose 1.29.2 使用 compose.json；迁移验收完成前不得加载 compose.workers.json。镜像变量全部要求固定镜像摘要，由镜像验证清单提供。shared 下环境文件、凭据和TLS证书不可提交；backend.env 使用 development 试用模式、容器网络端点和独立Temporal命名空间，自动分析目标留空。

唯一宿主发布地址为127.0.0.1:18443，先经SSH隧道验证；不绑定所有网卡。Nginx认证覆盖全部网页/API，验证必须信任指定CA，不使用跳过TLS校验。

服务启动顺序：数据库及存储 → Temporal数据库与服务 → 初始化独立命名空间 → 数据恢复与对象哈希校验 → API与网关 → 无模型验收 → Worker与分发器。所有命令使用独立项目名autoeval-platform，不操作现有测评容器。

当前未完成：镜像摘要锁定、后台镜像构建、秘密配置、TLS和账号、有效数据关系闭包导出、恢复及验收。不能将全量源库或旧Outbox直接导入并启动分发器。
